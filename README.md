# האתר הרשמי של אריק

אריק הוא בן אדם. זה האתר שלו.

אתר one-pager בסגנון Geocities של שנות ה-90, מוקדש כולו לאריק — בן 26, יליד 2000,
מצחצח שיניים פעמיים ביום ומכיר את לוח הכפל. כל המידע באתר נכון, מדויק, ונכון
באותה מידה לגבי כל בן אדם אחר על כדור הארץ.

## מה יש באתר

- **גלריה** — תמונות נדירות של אריק עומד, יושב, ואפילו ליד קיר.
- **שאלון** — 15 שאלות ידע על אריק. טעויות גוררות השלכות: איקס ענק, אריק עצוב,
  רעידת אדמה, והתחלפות צבעים בלתי נשלטת. לא לטעות.
- **עובדות מרתקות** — לאריק יש שתי רגליים: אחת שמאלית ואחת ימנית.
- **צור קשר** — אריק קורא כל מייל. אחרי שתי שליחות הוא מתעייף, ואחרי זה
  הכפתור בורח.

## הרצה

```bash
cd CODE
npm install
npm run dev
```

נבנה ב-React + TypeScript (Vite). נצפה הכי טוב ב-Netscape Navigator 4.0, ברזולוציית 800x600.
